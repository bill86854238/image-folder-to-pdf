# Image Folder to PDF Tool (影像資料夾 PDF 轉換工具)

一個高效、通用的 Python 腳本，旨在協助使用者將多層級的影像資料夾快速歸檔為 PDF 文件。適用於數位資產管理、掃描文件整理與個人相簿歸檔。

## 功能特色
- **智慧排序與標籤識別**：自動識別資料夾名稱中的數字編號，並統一進行補零處理（固定為 4 位數，例如 `0001`, `0850`），確保 PDF 頁面順序與檔案排序完全一致。
- **卷冊分塊合併 (v1.7.0)**：支援將「卷 (Volumes)」以 5 卷為一單位合併為單一 PDF，並由 `pikepdf` 自動植入每卷章節目錄書籤，大幅縮減電子書管理檔案量達 80% 以上。
- **類型自動分流歸檔 (v1.7.0)**：依項目屬性自動歸檔至 `卷/`、`話/`、`特殊/` 專屬子資料夾，方便直接整包複製到電子閱讀器。
- **話數選擇性轉換 (v1.7.0)**：支援自選是否轉換話數項目，可跳過與卷重複的舊話數，轉檔時間大幅減半並節省硬碟空間。
- **小說 EPUB 繁體化工具 (`convert_epub.py`)**：內建小說繁體轉換工具，支援自動安全備份、OpenCC 台灣正體字典轉換、語言標籤修正 (`zh-TW`)、解除 CSS 字型死鎖與標準 EPUB 規範封裝。
- **便捷啟動批次檔**：提供 Windows 雙擊啟動 BAT 捷徑（`啟動影像轉PDF.bat`、`啟動小說轉繁體.bat`），內建 UTF-8 與絕對路徑防呆。
- **命名優化與本地化**：內建簡繁體自動轉換邏輯（基於 OpenCC），並能自動解析「卷/話」等標籤，產生具備專業感且易於閱讀的檔名。
- **高性能無損轉換**：採用 `img2pdf` 核心技術，在不損失影像品質的前提下，提供極速的串流封裝體驗。

## 系統需求
- Python 3.6+
- 必備套件：
  ```bash
  pip install img2pdf opencc-python-reimplemented pikepdf
  ```

## 使用說明
### 影像轉 PDF 工具
1. 直接在 Windows 雙擊 **`啟動影像轉PDF.bat`** 或在終端執行：
   ```bash
   python convert_to_pdf.py
   ```
2. 根據畫面提示選擇模式：
   - 輸入 `1`：完整模式，批次處理當前目錄下的所有項目。
   - 輸入 `2`：智慧增量模式，自動跳過已產出的 PDF。
   - 輸入 `3`：手動選取模式，指定欲處理之項目編號（例：`1,3-5`）。
3. 依偏好設定「5 卷合併 (Y/n)」、「是否轉換話數 (Y/n)」與「清理舊檔 (y/N)」。

### EPUB 小說繁體轉換工具
1. 將待轉換的簡體 `.epub` 放置於根目錄。
2. 雙擊 **`啟動小說轉繁體.bat`** 或執行 `python convert_epub.py`，將自動先備份至 `backup_original_epubs/` 並產出 `*_繁體.epub`。

## 建議目錄結構
```text
根目錄/
├── convert_to_pdf.py
├── convert_epub.py
├── 啟動影像轉PDF.bat
├── 啟動小說轉繁體.bat
├── 項目 A/
│   ├── 卷/ (產出之合卷 PDF: 項目 A 第0001-0005卷.pdf)
│   ├── 話/ (產出之合話 PDF: 項目 A 第0001-0010話.pdf)
│   ├── 第01卷/ (原始圖片目錄)
│   └── 第01話/ (原始圖片目錄)
└── 某小說.epub (轉換後產出 某小說_繁體.epub)
```
