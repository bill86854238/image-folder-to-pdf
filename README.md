# Image Folder to PDF Tool (影像資料夾 PDF 轉換工具)

一個高效、通用的 Python 腳本，旨在協助使用者將多層級的影像資料夾快速歸檔為 PDF 文件。適用於數位資產管理、掃描文件整理與個人相簿歸檔。

## 功能特色
- **智慧排序**：自動識別資料夾名稱中的數字編號，並統一進行補零處理（固定為 4 位數，例如 `0001`, `0850`），確保 PDF 頁面順序與檔案排序完全一致。
- **多模式批次處理**：
    - **自動模式**：掃描根目錄下所有子目錄，一鍵完成大規模轉換任務。
    - **選取模式**：提供互動式清單，支援透過編號多選特定項目，靈活管理處理對象。
- **命名優化與本地化**：內建簡繁體自動轉換邏輯（基於 OpenCC），並能自動解析「卷/話」等標籤，產生具備專業感且易於閱讀的檔名。
- **高性能轉換**：採用 `img2pdf` 核心技術，在不損失影像品質的前提下，提供極速的轉換體驗。
- **寬廣的格式支援**：支援 `JPG`, `JPEG`, `PNG` 等主流影像格式。

## 系統需求
- Python 3.6+
- 必備套件：
  ```bash
  pip install img2pdf opencc-python-reimplemented
  ```

## 使用說明
1. 將 `convert_to_pdf.py` 放置於影像項目的根目錄。
2. 執行腳本：
   ```bash
   python convert_to_pdf.py
   ```
3. 根據畫面提示選擇模式：
    - 輸入 `1`：處理當前目錄下的所有資料夾。
    - 輸入 `2`：列出清單後，輸入編號（多選請用逗號隔開，如 `1,3,5`）進行處理。

## 建議目錄結構
```text
根目錄/
├── convert_to_pdf.py
├── 項目 A/
│   ├── 第01部分/ (內含圖片)
│   └── 第02部分/ (內含圖片)
└── 項目 B/
    └── 第01部分/ (內含圖片)
```
轉換後的 PDF 將會自動儲存於各項目的主資料夾內（例如：`項目 A/項目 A 第0001部分.pdf`）。
